# 🎙️ AI Voice Assistant using Meta LLaMA 2


An AI-powered voice assistant that accepts text or voice input, generates responses using Meta LLaMA 2, and converts the response into speech.

## 📸 Project Demo

<img src="./screenshot.png" alt="AI Voice Assistant" width="800"/> 

## 🚀 Features


- 🎤 Voice input
- 💬 Text input
- 🧠 Meta LLaMA 2 for AI responses
- 🗣️ Speech-to-text
- 🔊 Text-to-speech
- 🌐 Gradio web interface
- ⚡ GPU/CUDA support


## 🛠️ Technologies Used


- Python
- PyTorch
- Hugging Face Transformers
- Meta LLaMA 2
- SpeechRecognition
- gTTS
- Gradio


## 🔄 Working


```text
User Voice/Text
       ↓
Speech Recognition
       ↓
Meta LLaMA 2
       ↓

       ↓
gTTS
       ↓
Voice Output
▶️ How to Run
Open the notebook in Google Colab.
Enable GPU:
Runtime → Change runtime type → GPU
Install the required libraries.
Log in to Hugging Face.
Run the notebook cells.
Launch the Gradio interface.
